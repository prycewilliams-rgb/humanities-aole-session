## 🚀 Adding to GitHub (alongside your Humanities AoLE session)

You already have a GitHub Pages site running at:
`https://prycewilliams-rgb.github.io/humanities-aole-session/`

### Option A — Add to the SAME repository (recommended)
1. Go to your **humanities-aole-session** repository on GitHub
2. Click **Add file → Upload files**
3. Upload `classroom_management.html`
4. Click **Commit changes**
5. Your URL will be:
   `https://prycewilliams-rgb.github.io/humanities-aole-session/classroom_management.html`

### Option B — Create a new repository
Follow the same steps as before but name it `classroom-management-pgce`.
Your URL will be:
`https://prycewilliams-rgb.github.io/classroom-management-pgce/`

- 5 interactive scenario questions with instant feedback and retry
- Score card on completion
